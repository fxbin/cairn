# studio/frontend/src/workbench/
> L2 | Parent: ../../../../AGENTS.md

工作台组件消费 desktop 门面。Workflow 历史来自 App；对话草案经用户显式确认。

AGENTS.md: 工作台入口与成员。
CapabilitySettings.tsx: 可选能力发现及工作区设置。
ChangesReviewPanel.tsx: 工作区变更及文件查看。
CommandPalette.tsx: 工作台命令查找与界面路由。
DiffViewer.tsx: 展示已取得的文件差异。
FilesPanel.tsx: 文件树与文件预览。
OpenLocationIcon.tsx: 对接宿主打开位置的图标。
ProviderSettings.tsx: Provider 配置、准入与模型选择。
QueuePanel.tsx: 持久队列列表及显式动作。
RecoveryPanel.tsx: 普通 Run 的另行对账及终止表单。
SessionRecallRail.tsx: 会话召回导航与当前锚点。
SessionRow.tsx: 会话列表操作与状态简报。
SidecarWorkbench.tsx: 侧栏标签与证据视图。
UsageView.tsx: 从宿主读取用量并展示。
WorkflowChatCards.tsx: 展示模型草案及权威实例步骤；保存需要用户动作。
WorkflowInstanceControls.tsx: 用链头、Run 和操作身份提交审批、对账与返工。
WorkflowsView.tsx: 浏览定义、权威历史与自主 Task。复用实例控制。
WorkflowVerificationSummary.tsx: 投影逐标准报告、覆盖与可追溯 Run。
composerContext.ts: 将显式引用组织成当前输入。
workflowConversation.ts: 校验草案形状并按 App 状态展示执行。
